## 一句话定位

**我们做的是《红色警戒 2》+《共和国之辉》的楚汉换皮版。**

学它，模仿它，先把它的玩法内核**刻**下来；不谈超越，谈比肩。
刻完之后，换兵种、换车辆、换建筑、换美术——也就是"换皮"。
再往后才是加国家：齐鲁燕赵魏秦，**但第一阶段只做两个国家**（汉、楚）。

这条定位是硬约束。任何"我觉得这样更酷"的自创玩法，都要先回答一句：
**RA2 里对应的是什么？** 答不上来，就先别做。

## 三个阶段（不要跳步）

### 阶段一：刻内核（当前重点）

**阶段一的验收口径（就这一条，别扩）：**
**汉、楚两个国家，遭遇战（Skirmish）模式能完整打完一局** ——
选地图 → 选阵营 → 开局 → 建立经济 → 造兵造塔 → 打垮对面 → 结算 → 再来一局。
结算与重开都通，这一阶段就算交付。

**明确不做（别自作主张）：**
- ❌ 战役模式（Campaign，每个国家一条剧情线）——太复杂，往后放
- ❌ 过场动画、任务简报、剧情演出
- ❌ 编辑器、联机、存档

刻的是遭遇战里的这些规则、节奏、手感：

- 建造栏：右侧竖栏，按分类切页，点图标建造，有排队和生产进度
- 基地车 → 展开成基地（我们的：军旗车 → 立旗扎营）
- 经济：矿车在矿区和精炼厂之间往返，矿会挖干，钱就是产能上限
- 电力：电厂供电，缺电生产变慢、防御塔停摆
- 建筑序列：电厂 → 兵营 → 战车工厂 → 雷达/科技 → 防御塔 → 超级武器
- 兵种克制：步兵 / 反装甲 / 空中 / 攻城，各有天敌
- 维修与修理：工程师进建筑修，维修车修载具
- 单位经验：杀敌升级，老兵更猛（三星）
- 手感：左键下令、双击选同类、编队、路径点、拖屏、边缘滚屏、缩放
- 胜负：推平对方所有建筑才算赢（不是打掉主基地就结束）

### 阶段二：换皮（美术与命名）

在阶段一的骨架上，把皮换成楚汉：

- 兵种 → 兵卒、弩手、子弟兵、轻骑……
- 车辆 → 战车、撞城车、维修车、粮车
- 建筑 → 兵营、仓廪、车马坊、大营、弩台、烽火台
- 美术：**手绘淡彩 + 细墨线**，与人物同一支笔，不要照片质感

换皮可以并行做，但**不许因为换皮而改规则**。

### 阶段三：加国家

阵营从 2 个扩到 6 个（齐鲁燕赵魏秦），每个国家一套特色兵种与建筑。
`world` 里 `visible` 数组目前写死 2 份，加国家要改这里。

## 给 AI 的六条硬规则

1. **不许自创玩法。** 新系统的第一版必须能在 RA2 里找到对应物，且行为一致。
2. **数值先对齐关系，再谈手感。** 先让"费效比""射程/视野比""造价梯度"和 RA2 同构，再做 ±20% 的微调。
3. **术语沿用玩家语言。** 建造栏、矿车、电力、科技树、超武、基地车——别另造词。
4. **手感优先于创新。** 左键下令、拖屏、边缘滚屏、双击全选这类操作，照 RA2 别改。
5. **美术一套笔。** 单位、建筑、地形、UI 图标统一手绘淡彩 + 细墨线；不要混写实贴图。
6. **不引入打包器。** `tsc` 直出，这是环境限制，不是偏好。
