# 楚汉 · 即时战略（网页版 RTS 小样）

一个跑在浏览器里的等距视角即时战略游戏。题材取自楚汉相争，玩法参照红警式微操 RTS：
运粮攒粮草、造兵营出部队、兵种相互克制、一路推平对方大营。

**当前版本：1.0 可玩竖切（楚汉两阵营）**

## 怎么跑起来

```bash
npm install --ignore-scripts
npm run build        # tsc 编译到 dist/
npm run serve        # 启动静态服务器
```

然后打开 http://127.0.0.1:5273/ 。

无需打包器：TypeScript 直接编译成浏览器可用的 ES 模块，PixiJS 通过 import map 加载。

## 操作

| 操作 | 说明 |
| --- | --- |
| 左键点选 / 拖框 | 选择单位，Shift 加选 |
| 右键 | 空地移动，点敌人攻击 |
| WASD / 方向键 / 鼠标贴边 | 平移视角 |
| 滚轮 | 缩放 |
| Ctrl+数字 / 数字 | 存编队 / 调编队 |
| Esc | 取消选择、退出建造 |
| 底部按钮 | 造建筑、造兵种、粮车 |

## 玩法循环

1. 粮车往返农田与仓廪运粮，换取粮草
2. 造兵营/车马坊，出兵出车
3. 兵种按弹头—装甲克制表互相克制（数值全在 `src/sim/stats.ts`）
4. 推平对方全部建筑即获胜，反之失败

## 兵种克制

```
弩(破甲) → 重甲 → 步兵 → 骑兵 → 弩
```

| 阵营 | 兵种 |
| --- | --- |
| 汉 | 汉卒（廉价长矛）、材官弩（远程破甲）、武刚车（结阵战车） |
| 楚 | 江东子弟（精锐重步）、楚骑（高速冲阵）、冲车（重甲攻坚） |

## 技术架构

```
src/sim/      纯模拟层：确定性 20Hz tick，无渲染、无 DOM，可在 node 里跑
src/render/   PixiJS 等距渲染层，只读模拟状态
src/input/    鼠标键盘 → 指令
src/ui/       DOM HUD
scripts/      headless 冒烟测试
```

模拟层与渲染层严格分离，模拟层不依赖浏览器，因此可以：

- 用 `npm run simtest` 在终端里跑完整对局（验证平衡、找死循环）
- 以后要加联机时，直接换成固定 tick 锁步同步，渲染层不用改

## 美术

全部程序化生成（几何图形烘焙成纹理），仓库里没有图片素材。后续可替换为写意/版画风格的美术资源。

## 路线图

- **1.0** 楚汉两阵营，3v3 兵种，单机遭遇战 ✅
- **2.0** 三方势力：共享基础兵种 + 每国特色兵 + 阵营特性修正
- **3.0** 七国、地图编辑器、战役、联机

## 平衡

所有数值集中在 `src/sim/stats.ts` 一张表里，包括血量、造价、射程、伤害、弹头克制矩阵。
目标是"没有哪个阵营能无脑赢"，而不是数值绝对对称。
