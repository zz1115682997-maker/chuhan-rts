一个跑在浏览器里的等距视角即时战略游戏。题材取自楚汉相争，玩法参照红警式微操：
**立旗扎营 → 运粮养兵 → 造工事打工事 → 兵种相克 → 推平对方大营**。

**当前版本：1.x 可玩**（系统基本齐了，差 AI 对新系统的使用和平衡调优）

## 怎么跑起来

```bash
npm install --ignore-scripts
npm run build        # tsc 编译到 dist/
npm run serve        # 启动静态服务器
```

然后打开 http://127.0.0.1:5273/ 。

无需打包器：TypeScript 直接编译成浏览器可用的 ES 模块，PixiJS 通过 import map 加载。

## 操作

默认是**红警式左键下令**，顶部按钮可切回传统的右键下令。

| 操作 | 说明 |
| --- | --- |
| 左键点自己的单位 | 选中 |
| 左键点地面 / 点敌人 | 移动 / 攻击 |
| 左键拖动 | 框选，Shift 加选，双击选中屏幕内同类 |
| **Shift + 左键点地面** | **追加路径点**，单位依次走过去 |
| 右键 | 取消命令（选中建筑时是设集结点） |
| Ctrl+数字 / 数字 | 存编队 / 调编队 |
| 中键拖动 / 空格+左键拖动 | 拖动地图（抓住地图拖） |
| WASD / 鼠标推窗口边缘 / 拖小地图 | 移动视角 |
| 滚轮 | 缩放 |
| F | 立旗扎营（选中军旗时） |
| 选中建筑 → 出售 | 返还 50% 造价 |
| 建造队列 / 已就绪 → × | 撤销，全额退款 |

## 玩法循环

1. 开局只有一面**军旗**，开到想要的位置按 F **立旗扎营**，建起大营
2. 造**仓廪**（落成附赠一辆粮车）→ 粮车往返农田运粮，经济启动
3. 造**兵营 / 车马坊**出兵，按弹头—装甲克制表配兵
4. 造**工事**：拒马连墙、弩台守家、陷坑阴人
5. 推平对方全部建筑即获胜

## 兵种与工事

| 阵营 | 单位 |
| --- | --- |
| 两边都有 | 侦察兵、兵卒、轻骑兵、工匠、战车、撞城车、维修车、粮车 |
| 汉（特色） | 弓弩手 |
| 楚（特色） | 江东子弟 |

| 工事 | 作用 |
| --- | --- |
| 拒马 | 挡路，可拖动连成一排墙 |
| 弩台 | 固定炮台，自动射击范围内敌人 |
| 陷坑 | 不挡路，可被攻击打掉，侦察兵能拆 |

克制关系：**弩(破甲) → 重甲 → 步兵 → 骑兵 → 弩**。数值全在 `src/sim/stats.ts`。

## 系统特性

- **战争迷雾**：亮区 / 灰雾 / 未探索三态，山河会挡住视线
- **修理**：工匠修建筑、维修车修单位
- **侦察兵**：跑得快、看得远，能拆敌方陷坑且自己不死
- **路径点、编队、撤销、出售**：红警那套基本操作都有
- **音效**：Web Audio 实时合成，仓库里没有音频文件

## 技术架构

```
src/sim/      纯模拟层：确定性 20Hz tick，无渲染、无 DOM，可在 node 里跑
src/render/   PixiJS 等距渲染层，只读模拟状态
src/input/    鼠标键盘 → 指令
src/ui/       DOM HUD + 开局界面 + 合成音效
scripts/      headless 冒烟测试
```

模拟层与渲染层严格分离，模拟层不依赖浏览器，因此可以：

- 用 `npm run simtest` 在终端里跑完整对局（验证平衡、找死循环）
- 以后要加联机时，直接换成固定 tick 锁步同步，渲染层不用改

## 美术

全部程序化生成（几何图形烘焙成纹理，含单位四朝向与攻击帧），仓库里没有图片素材。
后续可替换为写意/版画风格的美术资源。

## 平衡

所有数值集中在 `src/sim/stats.ts` 一张表里：血量、造价、射程、伤害、弹头克制矩阵、工事参数。
目标是"没有哪个阵营能无脑赢"，而不是数值绝对对称。
