# 给豆包

做图之前先把这封读完。不要先画。画完的文件名按下面的来，放到对应文件夹，不要另起一套名字。

## 这个游戏现在是什么

浏览器里的楚汉即时战略，斜 45 度，菱形格子，像红警 2 的遭遇战。只有汉、楚两个阵营。同一张图两边共用，运行时再染成蓝和红。所以人物、车、房子都要灰白、低饱和，不要先画成红盔甲或蓝盔甲，染上去会脏。

人和大部分房子已经是你画的那一套，玩家认这套。现在难看的是地面和树，再加上一座还没换成你的画的水塔，一辆还是人拉的粮车。

## 玩家定过的一句，照这个改

人和建筑是画出来的。草地、土、水、石头如果像照片，叠在一起就是一个像画、一个像照片。玩家听完说：完全同意，就是这种感觉。

所以这次不是把画面画得更像真照片，是把地面、树、水塔、粮车收成和现有兵、房子同一支笔：手绘、淡彩、边缘清楚、灰白，放在菱形格上不突兀。

## 你要交的四样

### 1. 树，重画

现在的树玩家觉得丑，和兵不是一套。

- 文件：`assets/terrain/tree.png`
- 一张，透明底，树干底部就是画面底边，游戏会把底边钉在格子上
- 斜 45 度看的树，不是俯视圆冠，也不是照片抠图
- 灰绿、低饱和，线条和现有兵卒、兵营一样粗
- 不要投影贴在图里。游戏自己会铺一层影子
- 旁边可以一起重画这三张，它们和树是同一批装饰，笔触必须和树一致，不能树是画、石头是照片：
  - `assets/terrain/stones.png` 一小堆碎石
  - `assets/terrain/hill.png` 一座石山
  - `assets/terrain/reeds.png` 一丛芦苇
- 这四张都是透明底，物体站在画面底边

### 2. 地面四张，重画

这四张不是立绘，是俯视、可平铺的地表。游戏会把它们斜切进菱形格。所以不要画地平线，不要画一棵作为主体的树，不要留白边。整张铺满，随便裁一块都还是同一种地。

笔触仍是手绘淡彩，不要照片里的一根根草、一粒粒沙子。

- `assets/terrain/grass.jpg` 灰绿草地
- `assets/terrain/dirt.jpg` 暖赭色干土，这是农田那一块的底
- `assets/terrain/water.jpg` 灰青的水，只有波纹，不要岸、不要石头
- `assets/terrain/rock.jpg` 灰褐色碎石地，铺满，不要单独一块大石头当主角

正方形。颜色均匀，四边的亮度和中间差不多，否则拼地图会有一块一块的暗角。

### 3. 水塔，换成你的画

现在水塔是程序画的几根木柱加一个水盆，只是占位。玩家要你换上。

- 文件：`assets/units/shuaita_art.png`
- 木质水塔，两层木架，顶上一个水槽。它是建筑，不是人
- 斜 45 度，和现有仓廪、兵营同一套透视、同一支笔
- 灰白低饱和，透明底，不要投影，不要字
- 建筑底边坐在画面底部，左右留一点空
- 占地是 2×2 格。画的时候旁边不要画人。体量比一个兵卒大，比仓廪小
- 长边 512 像素，PNG，带透明

### 4. 粮车改成牛拉，不要人拉

现在 `assets/units/grainCart_v.png` 是人在拉车。这张要改掉。画面里不要人。

是牛拉车：一头牛在前面拉，木轮粮车在后面。不是人拉，不是人推，车上也不要站车夫。

- 还是这个文件名：`assets/units/grainCart_v.png`
- 牛在前，车在后，面向右下
- 灰牛、灰白木车，低饱和，透明底，不要投影，不要字
- 牛蹄和两个车轮踩在同一条底边上，不要一高一低
- 长边 512 像素，PNG，带透明
- 不要另外画走路帧。粮车没有攻击，一张站立就够

## 不要动的

兵卒、侦察兵、工匠、弓弩手、江东子弟、轻骑兵、战车、撞城车、维修车、军旗，以及兵营、仓廪、车马坊、大营、弩台、烽火台：这些已经在用，这次不要重画，也不要改文件名。拒马和陷坑是程序画的，因为要拼接，这次也不用你画。
