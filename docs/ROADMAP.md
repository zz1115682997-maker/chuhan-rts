## 2.0 三国 —— 规划

**目标**：验证"共享基础兵 + 每国特色兵 + 阵营特性修正"这套低成本扩展结构是否能成立。

### 结构（设计已定，见 [DESIGN.md](DESIGN.md) 第 11 节）

- **共享基础兵 3 个**：步兵、远程、重甲/车。所有国家数值相同
- **每国特色兵 1 个**：该国性格的唯一体现
- **阵营特性修正 1 套**：造价 / 速度 / 血量的小幅百分比修正

### 工作项

- [ ] 数据层重构：把"单位归属某阵营"改为"基础兵 + 特色兵 + 特性修正表"
- [ ] `menu.ts` 支持 3 个阵营卡片
- [ ] 第三个势力的历史背景与特色兵设计（待与用户确定，候选：秦 / 魏 / 齐）
- [ ] 特性修正表接入 `stats.ts`（造价、速度、血量系数）
- [ ] AI 适配多阵营
- [ ] 平衡：三国两两对位共 3 组，每组跑 AI 互打验证胜率

## 3.0 七国 —— 远期

- [ ] 七个势力，全部沿用 2.0 的扩展结构
- [ ] 地图编辑器
- [ ] 战役模式（过场、关卡目标）

2. 新增未完成项就加进对应版本的表
3. 修掉一个已知问题就从底部清单移除
4. 每次 `git commit` 有实质性进展，在"进度记录"加一行
